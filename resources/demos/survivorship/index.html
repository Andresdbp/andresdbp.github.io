One age class = one tenth of the maximum lifespan. n(x) is survivors per 1000 born — the quantity on the y-axis. l(x) = n(x)/1000, the proportion of the original cohort still alive. q(x) = [n(x) − n(x+1)] / n(x), the fraction of those still alive that dies during class x. Undefined for the last class.

 

What this is for

The misconception: students memorise three curve shapes — one that sags, one that is straight, one that plunges — and never notice the y-axis is logarithmic. They then read any straight line as Type II and any plunging line as Type III, on whatever axis happens to be in front of them. Press Linear: the Type II data is now a plunging curve that looks a lot like Type III, and it did not change by a single individual.

What to notice: Type II does not mean "a straight line". It means a constant proportional death rate — here 49.9% of whoever is still alive dies in every age class, which the q(x) bars show as ten identical bars. Losing half of 1000 is a drop of 500 individuals; losing half of 32 is a drop of 16. A linear axis draws those as wildly different falls. A log axis draws them as the same fall, because equal vertical distance on a log axis means equal proportion, not equal count. That is the only reason the straight line appears.

Where the model simplifies: these curves come from one smooth equation, n(x) = 1000 × 10−3(x/10)p, with p alone setting the type. Real cohorts are ragged and almost never sit exactly on one of the three types — drag the "your species" slider and most of its range is in between. Type I, II and III are reference shapes for comparison, not three boxes that every species falls into. Every curve here is also forced to end at exactly 1 survivor per 1000 at maximum lifespan so the three can be compared; real species differ in that too. And note the axis floor: the linear axis can show zero survivors, the log axis never can, because log(0) does not exist.
